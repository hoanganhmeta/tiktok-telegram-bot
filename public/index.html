🤖 Telegram Bot Webhook

Setup webhook cho TikTok Telegram Bot

📌 Hướng dẫn: Nhập Telegram Bot Token và Webhook URL, sau đó nhấn "Setup Webhook" để kích hoạt bot.
💡 Lấy từ @BotFather trên Telegram
💡 URL từ Netlify deployment của bạn

Đang xử lý...

📋 Các bước Setup:

1
Tạo Bot: Mở Telegram, tìm @BotFather, gửi /newbot
2
Lưu Token: Copy token từ BotFather và dán vào ô "Telegram Bot Token"
3
Triển khai Netlify: Deploy code trên Netlify và lấy URL
4
Setup Webhook: Nhập Token và URL, rồi nhấn "Setup Webhook"
5
Test Bot: Mở Telegram và gửi /start hoặc /tt username
